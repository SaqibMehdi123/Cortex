Rules
  • One accent — pine — reserved for active states, primary buttons, progress and focus
  • Semantic colors only for status: success, warning, danger
  • Hairline borders + soft 1px shadows; no heavy drop shadows
  • Hover reveals actions; resting chrome stays quiet
  • Radius: 12 cards · 8 controls · 999 chips
  • Motion: 150 ms ease-out on hover, press, chevrons and pane swaps
What changes vs today
  • Serif display headers → tight Inter headings (Linear-style crispness)
  • Solid FontAwesome icons → one consistent 16px stroke icon set
  • Loud borders → hairlines with surface contrast doing the work
  • Milestones stretch the page → in-card scrollers (fade + thin bar)
  • CV flow in a cramped dock → full-width agent view
  • Unchanged: warm paper palette, pine accent, GOAL_COLORS, all features
Homepage untouched — the refresh applies to the logged-in workspace only. The landing page you like stays exactly as it is.
